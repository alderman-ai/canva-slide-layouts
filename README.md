# canva-slide-layouts

A Markdown-first slide system: a library of slide layouts as hybrid Markdown (flat frontmatter for retrieval, an element table for geometry), a formal ontology and controlled vocabulary, per-presentation projects that turn local context into fully filled slides, and a batch upload into Canva through the Canva MCP. Also an Obsidian vault and a PowerShell toolchain.
